## THE THREE THINGS THAT UNBLOCKED IT (the actual fixes)

### 1. Gloss / enrichment off the L0 commit gate (L0-A deterministic floor)
`validate_l0_spec.py` now lets an empty-gloss record commit as honest canonical L0 (an abstention, not a
fabrication). `PARSED` still requires a deterministic lemma. Regression F10. This means **RAW-L0
(deterministic) commits instantly, no model** — so ingestion never blocks on the model.

### 2. The generative stage is now Hermes, not a stub
`auto_translate_raw.py` + `batch_translate.py` call **`model.chat → hermes -z`** — the real Hermes agent
running the translation skills — instead of the previous stub/direct-adapter path. This is what produces
actual scholarly translations (grammar `[G]`, reconstruction `[R]`, anchor `[A]`, parallel `[P]`, Krama
doctrine term handling).

### 3. The PATH bug that silently killed cron-spawned runs
The watchdog/cron spawns with a minimal PATH that **excludes `/usr/local/bin`**, so the runner crashed with
`No such file or directory: hermes` on every work. Fixed by exporting the full PATH in
`watchdog_auto_translate.sh`. Verified: watchdog restart → runner actively translating.
