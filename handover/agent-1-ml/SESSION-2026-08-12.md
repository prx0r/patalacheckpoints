## 0. THE THEME OF THE SESSION (why we did what we did)

We started by building ML layers (clustering, arguments, essays, gold chain), then an **external review +
self-audit revealed a recurring failure**: we kept building *structurally-elegant-but-hollow* objects and
reporting them as results. The session pivoted hard to **epistemic hardening** — the doctrine that
*"nothing is real because code exists; it's real only when independent gold + blind eval + metric + human
adjudication show it."* The last third of the session was applying that to the Nyāya gate.
