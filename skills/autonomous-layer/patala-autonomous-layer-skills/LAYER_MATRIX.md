# Layer Factory Matrix

The canonical stack: `SOURCE → L0/L1 → L2 → L200 → C1 → {THEME, ARGUMENT} → SYNTHESIS → ESSAY → EDUCATION`.

| Layer | Eligible when | Model job | Hard commit gate | Durable authority |
|---|---|---|---|---|
| L0 | source version lacks acceptable L0 | token gloss/close proposal | P0 + schema + false-certainty policy | machine proposal + deterministic proof dimensions |
| L1 | L0 committed | controlled translation | lossless spans + avagraha preserved + no doctrinal supplementation | MACHINE_PROPOSED |
| L2 | L1 committed | readable prose ("what does it say?") | content(L2) ⊆ content(L1) + declared_supplies (semantic-fidelity validator) | MACHINE_PROPOSED |
| L200 | L2 committed + refs complete | audit (how was the reading derived?) — partly deterministic | 8-section schema (derivation map, MT/IA split, typed crossrefs, review state); Task-2 fidelity | derivational proof object |
| C1 | L200 ENGINEERING_VALIDATED | passage commentary ("what does it mean?") | C1 quality test (local, no modern comparison, no essays-as-evidence, boundaries explicit) | MACHINE_PROPOSED commentary |
| THEME | enough C1 coverage | evidence-backed synthesis across C1s | every member claim has C1 evidence; not cluster=theme | MACHINE_PROPOSED theme |
| ARGUMENT | C1 committed | local argument structure | propositions/inferences evidence-backed (Agent 1's gold chain) | MACHINE_PROPOSED argument |
| SYNTHESIS | ARGUMENT + THEME | cruxes + epistemic ceiling | synthesis audit (every claim derivable from argument) | MACHINE_PROPOSED synthesis |
| ESSAY | SYNTHESIS | render structured synthesis into prose | proof-carrying: every sentence evidence-audited | MACHINE_PROPOSED essay |
| EDUCATION | ESSAY | lesson/explainer projection | authority(Education(x)) ≤ authority(x) | derived rendering |

No downstream layer treats a fluent upstream machine proposal as human/specialist review.
Three states per layer: GENERATED → ENGINEERING_VALIDATED → SPECIALIST_REVIEWED (a downstream layer's
eligibility depends on which state it may consume).
