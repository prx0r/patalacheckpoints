# Purpose

Produce the L200 **audit**: how exactly the published L2 reading was derived from the source —
the derivational proof object of the translation stack. NOT a readable summary (that's L2) and NOT
commentary (that's C1).

## Authority boundary
- Mostly deterministic: derivation map, source hashes, upstream IDs, review history are read from the
  graph, NOT regenerated by the model.
- Model proposes only what the graph cannot supply: candidate MaterialTranslationDecision
  classification, candidate InterpretiveAssertion, open-item detection.

## Required inputs per item
- `object_id` · L2 committed ref · L1 committed refs · L0 committed refs · source span refs · argument/read-map

## Output contract — the frozen 8-section schema
```
0 Identification
1 Published Reading
2 Derivation Map          L2 sentence -> argument-map unit -> L1 -> L0 span -> source span
3 Material Translation Decisions   SUPPLIED / REFERENT_SUPPLY / STRUCTURAL_CONNECTIVE / LEXICAL / GRAMMATICAL
4 Interpretive Assertions          IA-001...
5 Source Layer                      kārikā / Vṛtti / Vivṛti / Abhinava / objection / reply / quotation
6 Typed Cross-references           ROOT_TEXT_CONTEXT / SAME_ARGUMENT_CONTINUATION / DOCTRINAL_PARALLEL / COMPARATIVE_PARALLEL / SECONDARY_SYNTHESIS
7 Open / Needs Review
8 Review State
```

## The strict rule
A phrase that is the translator's paraphrase of the meaning is an EXPLANATORY_RESTATEMENT → §4 IA,
NOT a translation decision in §3. Never claim an explanatory summary is a translation intervention.

## Hard commit gate (Task-2 fidelity)
- derivation map covers every L2 ¶ (L2 → argmap → L0 range → source range)
- every §3 decision is genuinely a translation intervention, classified, not an IA
- §4 IA separate from §3 MT · §5 speaker tagged · §6 refs typed · §7 OPEN has status+anchor · §8 review state
- reference model: `l200/README-L200-SPEC.md` + the three canonical chunks (V2-O, V3-B, V3-C)

## Certificate
Task-2 on the gold chunks (18/19 pass) · hidden gold · human editor review (≥ editor) before the L200 is
surfaced as authoritative. L200 is the highest-value autonomy certificate.
