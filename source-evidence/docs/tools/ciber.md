# CIBER — deliberate refutation retrieval

**What Pāṭala borrows:** retrieves both corroborating and refuting evidence for scientific claims,
rather than conventional one-directional similarity RAG (which self-confirms).

**License:** research (paper). Ref: `arxiv.org/abs/2503.07937`.

## How Pāṭala consumes it
**PLANNED.** Native Pāṭala behavior: for every claim run SUPPORT + QUALIFICATION + REFUTATION queries
(`08-verification-plane.md`). Stronger than "find passages similar to the claim."

## Doctrine
Search for disconfirmation deliberately — the anti self-confirmation discipline.
