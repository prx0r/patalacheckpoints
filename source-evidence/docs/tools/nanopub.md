# Nanopub — assertion publication protocol

**What Pāṭala borrows:** the nanopublication protocol — creating, signing, publishing, searching, and
querying machine-addressable, citable assertions. Ecosystem: `nanopub-java`, `nanopub-py`, `nanopub-js`,
`nanopub-server`, `nanopub-query`, `nanopub-http`.

**License:** protocol (varied implementations). Repo: `Nanopublication`.

## How Pāṭala consumes it
**PLANNED.** A publication protocol, NOT our epistemology:
```
Pāṭala Assertion (native rich object)
   → publish()
   → Nanopublication
```
A scholar could cite `Utpaladeva asserts P / Abhinavagupta interprets P as Q / Passage X supports /
Scholar Y adjudicated` as machine-addressable objects.

## Doctrine
Don't turn Pāṭala into nanopubs; use nanopubs as the assertion-publication/export adapter.
