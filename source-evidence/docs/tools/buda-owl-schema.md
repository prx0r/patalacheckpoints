# BDRC owl-schema — Buddhist digital ontology (identity reference)

**What Pāṭala borrows:** the Buddhist Digital Resource Center (BDRC) ontology — Person/Work/Instance/
Place/Role/Event/Binding/Script/Collection for huge Asian textual collections. RDF, JSON-LD context,
SKOS schemes, inference rules, role vocabularies, admin metadata.

**License:** CC0. Repo: `buda-base/owl-schema`.

## Why it matters (reference, NOT canonical)
Don't invent what "Person authored Work / Work has Instance / Instance is manuscript X / Person copied
manuscript / Work comments upon Work" means without examining a mature Asian textual ontology.
Especially useful for the **PANDiT layer**.

**ADAPTER / reference, NOT canonical schema.** Pāṭala has unusual things BDRC doesn't: Argument, Claim,
EvidenceUse, TranslationChoice, EpistemicCeiling, Crux, Adjudication — those remain native.

## How Pāṭala consumes it
**PLANNED.** Crosswalk Person/Work/Instance semantics against BDRC for the PANDiT/identity layer.

## Doctrine
Borrow the mature ontology as a crosswalk reference; keep the epistemic core native.
