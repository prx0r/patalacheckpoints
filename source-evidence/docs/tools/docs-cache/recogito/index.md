# Recogito Studio
An Extensible Platform for Collaborative, Standards-Based Annotation of TEI Text, IIIF Images, and PDFs. Modern, Open Source, and Easy to Use.[Get Started](/guides/overview/)[Get a Demo](https://www.performantsoftware.com/pages/recogito/)
## Key Features
[Section titled “Key Features”](#key-features)

📝 Multi-Format Annotation

Annotate TEI XML texts, IIIF images, and PDF documents with standards-based W3C Web Annotations.

👥 Real-Time Collaboration

Multiple users can annotate and discuss documents simultaneously with live updates and commenting.

🔌 Extensible Plugin System

Build custom annotation tools, import/export formats, and integrations using the comprehensive SDK.

🚀 Self-Hosted & Open Source

Deploy on your infrastructure with Docker. Full control over your data and customizations.
