# Welcome to the h Documentation!

[h](https://github.com/hypothesis/h) is the web app that serves most of the
[https://hypothes.is/](https://hypothes.is/) website, including the web annotations API at
[https://hypothes.is/api/](https://hypothes.is/api/).
The [Hypothesis client](https://github.com/hypothesis/client)
is a browser-based annotator that is a client for h’s API, see
[the client’s own documentation site](https://h.readthedocs.io/projects/client/)
for docs about the client.

This documentation is for:

- 

Developers working with data stored in h

- 

Contributors to h
