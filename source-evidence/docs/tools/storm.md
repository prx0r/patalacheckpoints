# STORM / Co-STORM — the "Perspective Collector" precursor (Vision 07)

**What Pāṭala borrows:** Stanford's open-source, perspective-guided question generation + simulated expert
conversations + human-AI collaborative exploration + moderator + multiple LLM "experts" + a dynamically updated
conceptual mind map + grounding on user documents + modular retrieval/model interfaces. This is almost exactly
Vision 07's "Perspective Collector" (TEXT SAYS / TRADITIONAL COMMENTARY / SCHOLAR A / SCHOLAR B / ALTERNATIVE /
MY READING / COUNTERREADING + find-interesting-tensions + scholar-directed exploration). **Don't build the
conversational exploration mechanics first.**

**License:** open (Apache-2.0).

## How Pāṭala consumes it (the major change)
```
Co-STORM discourse protocol
   + Pāṭala graph retrieval (PaperQA2/SciRAG)
   + Pāṭala positions / commitments / cruxes
```
Co-STORM's mind-map nodes become **Pāṭala-resolvable propositions/themes** rather than disposable generated
summaries. This accelerates the Workbench enormously.

**Priority: prototype (replace STORM's retrieval with Pāṭala/PaperQA and test the Vision-07 Perspective
Collector).**
