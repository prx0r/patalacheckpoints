saridvānabhisambandhād indunārkasya sannidhau vikaroti yathā lolaiḥ kallolairnādayannabhaḥ //
puṃsāmapratighodāramarīcinicayena ca ratnānīṣṭavidhānācca bindvādyāḥ śivaśāsane //
aṣṭāvanantapūrvāste yathāpūrvaṃ guṇādhikāḥ tathā purāṇi tatraiṣām anantaḥ parameśvaraḥ //
sati bāhye tadajñānaṃ vastuni syāt tamaḥkṛtam tamasācchādyamānā hi na te muktā bhavanti ca //
yā taysa vimalā śaktiḥ śivasya samavāyinī saiva mūrtiḥ kriyābhedāt sādākhyā tanurucyate //
antaḥsaṃjalparūpā tu na śrotramupasarpati prāṇavṛttimatikramya vartate madhyamāhvayā //
pratiṣṭhāyāṃ tu catvāri kalāyāmavanīṃ vinā bhūtāni pañca tanmātrāḥ pañca karmendriyāṇi ca //
binduśaktiśivākhyāni trīṇi siddhāntasāgarāt samuddhṛtya satāṃ dhartuṃ hṛtkaṇṭhaśravaṇe sadā //
tatra sannidhimātreṇa vidadhātyakhilaṃ citiḥ yathārko dinaceṣṭānāṃ sannidherupakārakaḥ //
saivonmiṣantī samprāptabindugarbhabharālasā patyurāviṣkarotyuccaiḥ paramānandasantatim //
advayeti niṣedho 'pi citi yujyeta tanmate(?) dvaitabhāvastato 'nyatra siddhyet siddhāvapi dhruvam //
anenaiva śarīreṇa parāṃ vyāptimakhaṇḍitām prāpnuvanti mahādhīrā dhanyā hi śivayoginaḥ //
māyā jaḍāntaravyāptā pariṇāmavatī ca yat niṣpādane kalādīnāṃ śarīrādisamanvitam //
kāryabhedādadhiṣṭhānavaśādekaiva pañcadhā sā bhāti binduśāntyādipañcādhiṣṭheyagocarā //
upādānaṃ śarīrāṇāṃ vidyāvidyeśvarātmanām kāryātmikā sā māyeyaṃ pariṇāmavatī ca yat //
sā tu saṃvidaśeṣārthagrahaṇe lampaṭodayā paramaiśvaryarūpā ca mahimā vyāptirūpiṇī //
pañca buddhīndriyāṇyāsan mano'haṅkārabuddhayaḥ avyaktamapi varṇāśca hādiṭāntā vilomataḥ //
na siddhaḥ sādhyate dharmo nāsiddhairapi taistathā siddhyasiddhī ca sambhūya naikatra sthātumarhataḥ //
śaktirāśayataḥ śambhoḥ sa ca tasyāstatastathā kāryopādhivaśācchaktisaṃjñā syādapi cidghane //
tamāsevya mayāpyeṣā binduśaktiśivāśrayā parīkṣā kriyate tatra bindurādau nirūpyate //
gaurbrāhmaṇo 'yamādityo yūpa ityevamādayaḥ naivaṃ heturadṛṣṭāyāṃ vyāptau sādhyaṃ na sādhayet //
nityaiṣāśeṣakāryāṇāṃ kāraṇatvād yatheśvaraḥ sattve kāraṇaśūnyatvād api binduvadiṣyate //
kṛtyeṣu teṣu kartāsau trividhaḥ pañcasūcyate śaktimānāhitodyogaḥ pravṛttaśceti deśikaiḥ //
yastvenaṃ manyate mohāj jaḍadhīrjaḍamīśvaram na tasya yuktiḥ śāstraṃ vā nātmā nāsti ca devatā //
na te viśvasya kartāraḥ kartāsya śiva eva yat na hi kartṛbahutvasya gamakaṃ vidyate kvacit //
nānumānāgamau tatra pramāṇaṃ tadabhāvataḥ pratyakṣa eva tāvarthe vikalpaviṣayāvapi //
binduḥ śāntiḥ kalā vidyā pratiṣṭhā sanivṛttikā bhogasthānāni pañcaiṣāṃ bindusaṃjñā śiveritā //
tathā parīkṣitā samyag āgamaiḥ sopapattikaiḥ vivartamānā jāteti naṣṭeti vividheti ca //
aśuddhayoraśuddhaiva māyāto dvividhā matā bindorviveke sahasā cchidyate malakambukaḥ //
bhadrakālyāśca bhuvane kṣakāro 'rṇeṣu kīrtitaḥ ekāśītipadā devī pratisargapadakramāt //
ityadvaitagrahāviṣṭāḥ pralapanto dayālubhiḥ gurubhiḥ pratibodhyante siddhāntāgamadāyibhiḥ //
na tānutpādayatyarthān asataḥ prathayatyasau jñānamātraṃ tathaiveyam ekānekāyate bhramāt //
śeyādhiṣṭheyakāryādau na tu hetvādikaṃ param tena śaktiḥ parāpekṣaṃ rūpamīśasya yujyate //
tathā hi tāṃ samāśritya santo 'nye śāśvatī satī yatsiddhau jagataḥ siddhir yadasiddhau na kiñcana //
vimucyerannṛte bindos tadvaicitryavidhāyinaḥ na hi cit pariṇāmena kurute tadaśeṣataḥ //
sa tayā jaḍamākramya sṛjatyavati hanti ca tirodadhāti bhagavān anugṛhṇāti cātmanaḥ //
bhittvā yaṃ bodhakhaḍgena nirgacchantyaviśaṅkitāḥ tāmeva vāṇīṃ sūkṣmākhyām āhurātmavido janāḥ //
samavetā śive bindur iti tatrābhidhīyate so 'yamātmani tattvaugham anekabhuvanāvalim //
anuviddhamiha jñānaṃ sarvaṃ śabdena jāyate saiṣā caturvidhā vṛttir nivṛttyādikalāśrayāt //
tattveṣu teṣu vijñānakevalānāṃ mahātmanām bhuvanāni vicitrāṇi svabhāvalalitāḥ priyāḥ //
nirmalānāmasaṃkṣobhād bindostadbandhamokṣajā nirvikalpārthasaṃvittis tadaharjātabālavat //
vidadhad vividhānalpatanubhogendriyādikam bindurākhyāyate yuktyā pariṇāmī pradhānavat //
jāyetānyacca bhagavān aśaktaḥ kiṃ kariṣyati ananyāpi tathā śambhor vibhinnā śaktiriṣyate //
devaḥ sadāśivastatra kalādhveti prakīrtitaḥ vyāpako bhuvanādīnām abhivyāptaḥ sa bindunā //
bhuvanādīnabhivyāpya pañca pañcasu vartate pītaiṣā caturaśrā ca kaṭhinā vajralāñchitā //
trayoviṃśatirāmnātāḥ ṣaṭpañcāśat purāṇi ca jalatejo 'nilākāśabuddhyavyakteṣvahaṅkṛtau //
hetūnapi parīkṣāyai lakṣayet tasya śāstrataḥ na hyatra śemuṣī śuddhā vipulāpi pragalbhate //
jāyate bindusaṃkṣobhād anantasyārthadarśane vidyāśarīro bhagavān anantaḥ kṣobhako mataḥ //
