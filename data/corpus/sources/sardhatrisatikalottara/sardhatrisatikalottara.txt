spandatyadharaṃ vaktraṃ netragātraprakopanaḥ udvejayati marmāṇi udāno nāma mārutaḥ //
kuṇṭhayitvā tataḥ snāyāc chivatīrthasya madhyataḥ cakravatyupacāreṇa sugandhāmalakādibhiḥ //
hṛdayenātra tūddhāraḥ kartavyaścāpyanukramāt uddhāre prokṣaṇe caiva tāḍane ca tathaiva ca //
dakṣiṇaṃ brahmayonistham ekameva tridhā sthitam pārśvabindudvayopetā sā rekhā madhyataḥ sthitā //
sa hakāro vakāreṇa yakāreṇa ca dīpitaḥ hyau madhye hlīṃ namaścānte vāruṇena tu buddhimat //
ataḥ paraṃ pravakṣyāmi aṣṭadhā pratyayo yathā anagnijvalanaṃ caiva vṛkṣasyālabhanaṃ tathā //
bahumaṅgalanirghoṣaiḥ śaṅkhavāditraniḥsvanaiḥ brahmaghoṣaiśca vividhair nṛttagītasamanvitaiḥ anujñāto 'bhiṣiktaśca ācāryaḥ pāśahā bhavet //
sṛṣṭinyāsaṃ nyasettatra dvirabhyāsapaderitam sravantaṃ cintayettasminn amṛtaṃ sādhakottamaḥ //
manasā manasi cchinne jīvaḥ kevalatāṃ vrajet vistaraṃ tyaja deveśa saṃkṣepātkathayasva me //
astrajaptena bhāgena diśāṃ bandhaṃ tu kārayet śivajaptena tīrthaṃ tu brahmajaptena vigraham //
prathamaṃ tasya tadbījaṃ nādabinduritīritam na jahāti paraṃ sthānaṃ śāśvataṃ dhruvamavyayam //
nādākhyaṃ yatparaṃ bījaṃ sarvabhūteṣvavasthitam muktidaṃ paramaṃ kiṃ ca divyasiddhipradāyakam //
jñātameva sakṛdyena vistṛtaṃ tu tadeva tat tatkāla eva mukto 'sau yadā jñātaṃ hi tatpadam //
praṇavādi tato huṃ phaṭ huṃ phaṭ huṃ phaṭ tathaiva ca phaṭ phaṭ phaṭ phaṭ phaḍevaṃ syād vāruṇena tu buddhimān udghātāṣṭaśatenaiva kṣipraṃ nāśayati jvaram //
ṣaṣṭhaṃ trayodaśāntaṃ ca pañcame viniyojayet śivaṃ tattu vijānīyān mantramūrtiṃ sadāśivam //
paśūnāṃ caiva nirdeśaṃ kathayasva maheśvara ādimasya dvitīyena gṛhītvātmānamātmanā //
evaṃ viditvā medhāvī ākarṣaṃ kurute dhruvam avijñāya tvidaṃ samyaṅ naiva siddhyate sarvadā //
lakṣāṇāṃ pañcaviṃśatyā viṣayaṃ vaśamānayet triṃśallakṣajapādasya vaśo vai maṇḍalī bhavet //
jīvasya puruṣākhyasya darśanaṃ śṛṇu ṣaṇmukha kathayāmi na sandehaḥ putrasnehādviśeṣataḥ //
śūnyamarutsaṃdaṃśakagṛhītakaraṇātmako hyubhayato 'pi / saṃyāti yatra neyaḥ śuṣkadalaṃ māruteneva //
māyāvini śaṭhe krūre niḥsattve kalahapriye gatibhraṃśakare yoge tattvaṃ tacchṛṇu ṣaṇmukha //
tamuddiśya kṛtaṃ karma mokṣadaṃ tanna saṃśayaḥ sūryasya grahaṇe vatsa viṣuvadyogasaṃyutam //
īkārādyantasaṃyuktaṃ hau ca madhye niyojitam prāṇānusvārasandīptaṃ namo 'ntaṃ praṇavaṃ punaḥ //
athātaḥ sampravakṣyāmi śāstraṃ paramadurlabham nāmnā tu vātulāttantrād dadhno ghṛtamivoddhṛtam //
ataḥ paraṃ pravakṣyāmi prāsādasya tu lakṣaṇam hrasvaṃ dīrghaṃ plutaṃ caiva lakṣayenmantravitsadā //
yāmye yāmyo bhāvo nairṛtye nairṛto vinirdiṣṭaḥ / vāruṇapatre vāruṇo mārutpatre gato marudbhāvam //
prāsādaḥ kīdṛśo jñeyo vyāptistasya ca kīdṛśī śarīraṃ kīdṛśaṃ tasya kathayasva maheśvara //
anyathā naiva mucyante vidhihīnāḥ ṣaḍānana pūrṇāhutipradānaṃ ca kartavyaṃ dhāraṇāyutam //
ātmādhidevatā mantrāñ jñātvā muktastu mocayet nāḍīvivarasambandhā ūrdhvanālā hyadhomukhāḥ //
buddhirmanastvahaṅkāraḥ puryaṣṭakamudāhṛtam yāvadetairna nirmuktaḥ kathaṃ mucyeta bandhanāt //
gāndhārī hastijihvā ca pūṣā caiva yaśāstathā alambuṣā kuhūścaiva śaṅkhinī daśamī smṛtā //
yā kalā rekhinī tatra patitā bindunā saha savidyeśaḥ śivaḥ prokto devadevaḥ sadāśivaḥ //
prayogeṇātisūkṣmeṇa yogadṛṣṭena mantravit divyena yogamārgeṇa śaktiṃ yaḥ prerayettu tām //
dhyāyanti paramaṃ haṃsaṃ prāsādaṃ nāmarūpataḥ vibhāgaṃ cāsya vakṣyāmi yaṃ dhyātvāmṛtamaśnute //
ṣaṇmāsājjāyate mṛtyur iti śāstrasya niścayaḥ dvitīyasyānucāreṇa ahorātraṃ sa jīvati //
svadehaṃ cintayedvidvān divyarūpamanaupamam yasya yatkarma coddiṣṭaṃ tatkarma paricintayet //
eṣā mudrā mahāmudrā sarvakāmārthasādhikā karanyāsaṃ purā kṛtvā mudrābandhaṃ tu kārayet //
nipatantī tridhā yāti śivavidyātmakairyathā śāntirvidyā pratiṣṭhā ca nivṛttiśceti tāḥ kalāḥ //
puryaṣṭakasamāyukto hyadha ūrdhvaṃ sa gacchati śabdaḥ sparśaśca rūpaṃ ca raso gandhaśca pañcakam //
upaspṛśya vidhānena saṃdhyāṃ vandeta sādhakaḥ mantraiḥ sarvaiḥ sakṛdvatsa upasthānaṃ tu kārayet //
vijñāya pūrvamādhāraṃ paścādādheyameva ca ādhārādheyavitprājñaḥ samarthaḥ sarvakarmasu //
brahmādyāñśrāvayedvatsa na punarjanmatāṃ vrajet tejaśceto dvirabhyasya āyāmo bhāskarasya tu //
udgāre nāga ityuktaḥ kūrma unmīlane smṛtaḥ kṛkarastu kṣute caiva devadatto vijṛmbhaṇe dhanaṃjayaḥ sthito ghoṣe mṛtasyāpi na muñcati //
agnīṣomātmakaṃ sarvaṃ jagatsthāvarajaṅgamam cintayedviparītaṃ tu siddhikāmaḥ samāhitaḥ //
visṛṣṭaṃ yena tadbījaṃ visargastena cocyate tena cāpūritamidaṃ jagatsarvaṃ ca tanmayam //
mṛṇmayaṃ kalaśaṃ hyekaṃ candanena vilepitam brahmapatrapuṭaṃ vātha padmapatramathāpi vā //
tileṣu ca yathā tailaṃ puṣpe gandha iva sthitaḥ puruṣastu śarīre 'smin sabāhyābhyantare sthitaḥ //
jalasnānaṃ purā kṛtvā astrabījena ṣaṇmukha vidhisnānaṃ tataḥ kuryān mūrdhna ārabhya mantravit //
īśānena śiraḥ snāyān mukhaṃ tatpuruṣeṇa tu hṛdayaṃ bahurūpeṇa guhyaṃ vai guhyakena tu //
etatte śivasadbhāvaṃ śivavaktrādviniḥsṛtam guhyādguhyatamaṃ guhyaṃ gūhanīyaṃ prayatnataḥ //
ityetadvāyuvṛndaṃ hṛdi ca vinihitaṃ nābhicakrapratiṣṭhitam niśvāsocchvāsakaiḥ śvasanapuramadhaḥ kampitāghūrṇitaiśca nityaṃ nityālpajanmā vyasanayati paśuṃ yauvane bālabhāve ākrānto vāyurekaḥ sa jananamaraṇaiḥ krīḍati bhrāntasattvaiḥ //
āyāmānte yadā cchinnaṃ tadā cotkramate dhruvam manasi grathitāḥ pāśāḥ sūtre maṇigaṇā iva //
jīvaḥ prayāti daśadhā tena cakraṃ prakīrtitam nāḍīcakramiti proktaṃ yena saṃkrāmati hyasau //
ardhamātrā parā sūkṣmā tasyā ūrdhvaṃ parātparam brahmā viṣṇuśca rudraśca īśvaraḥ śiva eva vā //
