# SPEC — ESSAY (the larger argument, from themes + comparison)

*The seventh layer. An ESSAY is where comparison, original argument, modern application, and
cross-tradition analysis properly occur. It synthesizes THEME dossiers + COMPARISON packs +
scholarship — and every claim points back down the stack.*

---

## 1. Derivation (never force)

```
C1s
↓
Theme: Memory and Recognition
↓
Theme: Non-constructed Self-awareness
↓
Theme: Unity of the Recognizer
↓
Essay: Why Recognition Requires More Than Memory in the IPVV
```

An essay arises only once a theme has enough local evidence.

## 2. What an essay may do (unlike C1)

- comparison (Ratié / Torella / Pandey / Dyczkowski / cross-school)
- original argument
- modern application
- broader philosophical synthesis
- cross-tradition analysis (e.g. the reflexion-vs-IPK 1.5.11 essay)

## 3. The killer feature — auditable essays

Every essay claim carries a **SHOW EVIDENCE** link:

```
SHOW EVIDENCE
→ IPK passage
→ IPVV passage
→ Sanskrit
→ translation decision
→ relevant scholarship
```

So the essay is auditable end-to-end: a reader jumps from any claim to the Sanskrit and back.

## 4. Example contribution chain (IPVV)

```
IPVV 1.5.11 (vimarśa = essence of light)
   ├ C1: reflexion is the essence, not a property
   ├ COMPARE: Ratié (FR) · Torella · Pandey
   ├ CONTEXT: IPK 1.5.11 root + Vṛtti + IPV parallel
   ├ THEME: "recognition / reflexivity / memory as the recognizer's continuity"
   └ ESSAY: "Reflexive Awareness in the Pratyabhijñā"
```

## 5. Factory rule

Essays are **downstream products** derived from the evidence stack — never written independently and
forced onto passages.

## 7. VALIDATION — how we know an ESSAY is correct

- [ ] every factual/scholarly claim carries a SHOW EVIDENCE link that resolves (passage → Sanskrit →
      decision → scholarship)
- [ ] it is derived from ≥1 theme dossier (not forced onto passages)
- [ ] where it cites an existing translation (Ratié/Torella/Pandey) it does so as an adversarial
      witness, classified (STYLE_ONLY … OMISSION), not copied as authority
- [ ] original argument and modern application are clearly marked as the essay's own (not presented
      as what the primary text establishes)
- [ ] the essays do not become PRIMARY EVIDENCE for the translation (per C1 §9 — essays are
      INTERNAL SYNTHESIS)
- [ ] it distinguishes the passage's claim from the essay's broader thesis (no collapsing)
- [ ] it cites our translation by stable passage ID, so the reader can jump to the Sanskrit
