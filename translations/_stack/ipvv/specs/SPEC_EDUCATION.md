# SPEC — EDUCATION (teaching the result clearly)

*The eighth layer. EDUCATION is how we teach the result — the pedagogic surface of the stack. It
sits above ESSAYS and distills them for a reader who is not yet a specialist.*

---

## 1. Derivation

```
SOURCE → L0/L1 → L2 → L200 → C1 → THEMES → ESSAYS → EDUCATION
```
EDUCATION is downstream of ESSAYS: it teaches what the essays argue, in clearer terms.

## 2. Education artifacts

- **3-minute explainer** — one idea, plain language.
- **Lesson / study guide** — a structured path through material.
- **Concept primers** — build on the concept dossiers (e.g. "what is vimarśa?").
- **Video / audio** — derived from the master note; assets in R2 (`SPEC_STORAGE_R2.md`).

## 3. Reading levels (the reader's zoom)

```
READ     "What does the text say?"         (L2)
STUDY    "What does this passage mean?"    (C1)
THEMES   "How does this idea develop?"     (THEME)
ESSAYS   "What larger argument follows?"   (ESSAY)
EDUCATE  "Teach me this clearly."          (EDUCATION)
```

## 4. Factory rule

Education is derived from the essay stack, which is derived from themes, which are derived from C1s,
which are derived from the translation. It never bypasses the evidence chain.

## 6. VALIDATION — how we know EDUCATION is correct

- [ ] it is derived from the essay/theme stack (not invented independently)
- [ ] it teaches one thing clearly (a normal reader understands it without prior specialization)
- [ ] where it cites a claim it does not distort the passage (it distills, it does not contradict)
- [ ] it links upward to the essay and downward to the passage (the chain is preserved)
- [ ] it is correct under the evidence (a specialist would not object to the simplification as
      false — only as simplified)
- [ ] video/audio assets are rights-tagged and stored in R2 per `SPEC_STORAGE_R2.md`
