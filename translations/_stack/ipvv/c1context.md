# C1 CONTEXT ENGINEERING — the agnostic skill for writing C1 passage-commentaries
## How to gather the right context so you can write intimate, passage-local C1 commentary well

*2026-08-11. This is the reusable, **essay-agnostic** skill for producing the CONTEXT that a C1
(passage-commentary) needs. It works for ANY Sanskrit/tantric/philosophical text — the IPVV, Kubjikā,
Buddhist texts, ritual manuals, goddess texts. The method: before writing a single C1, gather the
layers of context that make the commentary *grounded* (anchored to the text and its scholarship) and
*insightful* (adding something the raw text does not supply). This is exactly the "context engineering"
that separates a restatement from a real commentary.*

---

## 1. THE GOAL (what C1 needs)

A good C1 is **intimate and passage-local** — it explains what this passage is *doing, saying,
presupposing, and implying*. It is NOT an essay, and NOT a restatement. To write it you need five
layers of context:

| Layer | What it supplies | Where from |
|---|---|---|
| **1. The text itself** | the passage + its root source (the kārikā/sūtra it comments on) | the on-disk edition + the base text |
| **2. The local argument** | what precedes/follows; the passage's function in the work | the argument map + the L2/L200 |
| **3. The scholarship** | what the specialists say; the rival readings | the scholar papers on disk |
| **4. The comparison** | parallel passages in the SAME author and in OTHER traditions | the comparative corpus (Tantrāloka, Spanda, etc.) |
| **5. The synthesis layer** | your own prior analysis (essays, dossiers) — so you don't re-derive from scratch | your research-library essays |

**The order matters.** Text → local → scholarship → comparison → synthesis. You never start with the
essay and force passages into it; you start with the text and let the context accumulate.

---

## 2. THE SEVEN-STEP CONTEXT GATHERING PROTOCOL

For ANY passage, run these seven steps. Each produces a named context-bundle you can paste into the C1.

### STEP 1 — Locate the text and its root source
- Find the passage in the on-disk edition (note the source file + line range).
- Identify the **root text it comments on** — for a commentary, this is the kārikā/sūtra/verse. For a
  ritual text, it's the ritual sequence or the deity-invocation.
- Record: *work, section (vimarśa/āhnika/paṭala), source lines, root kārikā*.
- **Why:** the C1 must know what the passage is *about*, and a commentary passage is always about
  something upstream.

### STEP 2 — Get the local argument
- Find the **argument map** for the passage (the project produces one per chunk: "reconstruct the
  argument, not the sentence").
- Note what **precedes** and **follows** — the passage's function in the larger arc.
- Record: *the passage's role in the section; what it presupposes; what it prepares*.
- **Why:** C1's FUNCTION and LOCAL CONTEXT sections come from here.

### STEP 3 — Read the audited reading (L2 + L200)
- Read the L2 (the readable prose) and, if it exists, the L200 (the derivation audit: how the reading
  was produced, what's SUPPLIED vs interpretive).
- Note the **load-bearing claims** and the **OPEN/uncertain items** (the honest boundary).
- **Why:** C1 must stay *honest to the derivation* — it must not contradict the audit, and it should
  surface (not smooth) the open items.

### STEP 4 — Mine the on-disk scholarship
This is the biggest layer. The project has **specialist papers on disk** for the recognition corpus
(see §3). For your passage:
- **Find the specialist(s)** who work on this text or tradition (for the IPVV: Ratié is the specialist;
  Torella, Timalsina, etc.).
- **Read their treatment** of the relevant doctrine (e.g. Ratié's ch. 2 on memory, ch. 7 on freedom).
- **Extract their analytic register** — HOW they write (quote the text, name the move, show what it
  presupposes). You are trying to write *in their register*, not just cite them.
- **Capture their vocabulary** (e.g. Ratié: "re-appropriation," "asampramoṣa," "vimarśa = the felt
  self-luminous grasping").
- Record: *the specialist's reading of this doctrine; the verbatim quote that anchors it; their
  register/vocabulary.*
- **Why:** the scholarship gives you (a) the established reading (don't reinvent it), (b) the rival
  readings, and (c) the voice to write in.

### STEP 5 — Find the comparisons (for later, NOT in C1)
- **Within the author:** does the same doctrine appear elsewhere in this work (a parallel passage)? For
  the IPVV, is the memory-doctrine restated in another vimarśa? (Useful for LOCAL CONTEXT and RELATED
  PASSAGES.)
- **Across the author's works and traditions:** the Tantrāloka, the Spandakārikā, the Śivasūtra, the
  Buddhist apoha, the Advaitin's ignorance — these are the cross-textual witnesses.
- **The rule (important):** cross-textual parallels are **NOT part of C1**. C1 stays strictly
  passage-local. Gather the witnesses now as a *note for later*, and place them in the **PARALLELS
  layer** (a separate, later layer after THEMES) — never in the C1 itself. This is what keeps C1 a
  local commentary rather than a synthesis.
- Record: *for the local move, note the candidate witnesses (work + relation + basis) in your scratch,
  to be promoted to the PARALLELS layer later.*

### STEP 6 — Pull your own synthesis (don't re-derive)
- Check your research-library for **essays, dossiers, and deep-dives** on this passage or doctrine.
  The project has already written these (e.g. the recognition essays). They are the synthesis layer.
- Use them as **reference arguments** — you lean on them, you don't re-derive the argument from scratch.
- Record: *which essays/dossiers cover this; the argument they make; the section that bears on this
  passage.*
- **Why:** the C1 must be consistent with the higher layers (themes, essays). If the essay says X and
  the C1 says not-X, you have a problem. The essays tell you where the passage is *heading*.

### STEP 7 — Search externally for what's not on disk
When the on-disk scholarship is thin, go external:
- **Academic search:** search for papers on the text/tradition/doctrine (e.g. via academia.edu, JSTOR
  summaries, PhilPapers, Google Scholar abstracts). You are looking for *scholars and works*, not full
  texts.
- **The "wisdom lib" / analysis sources:** search for popular or comparative analyses of the same or
  related texts (e.g. Dyczkowski's writings, lectures, modern treatments) — to see how the doctrine is
  popularly framed, so your C1 can be clear without being reductive.
- **Related translations:** search whether an English translation of the passage/work exists (so you
  can cite it or note its absence). For the IPVV, note "no complete English translation exists" —
  that's a relevant fact.
- **Verify, don't guess:** use web fetch to confirm a scholar's name/work exists before citing it.
  Record: *what was found, the source URL, and the relation (scholarly / comparative / popular).*
- **Why:** the context must be complete. But note the rule: **only cite what you can verify.** A
  half-remembered paper is a hallucination risk — fetch and confirm.

**The 31 specialist papers** (in `corpus/ipvv-anchor/scholarship/`):

  Pratyabhijñā*, *How free is imagination*, *On reason and scripture*, *The Dreamer and the Yogin*,
  *Utpaladeva on the Power of Action*, *Dharmakīrti against the pudgala*, *Can one prove that something
  exists beyond consciousness*, etc.
- **Direct anchors:** *Pratyabhijñā: Recognition's Nature and Cause*, *Dharmakīrti's Theory of
  Exclusion (apoha)*, *Around Abhinavagupta*, *The Pratyabhijñā on Consciousness*.
- **Timalsina** (subjectivity, the body, meditation) and others.

**The broader paper dump** (`sanskritree/abhinavagupta/`): 802 PDFs (43 zips) — the deep end if the
specialist set is thin on a specific doctrine.

**The rule:** always check the **MANIFEST** for the text you're working on — it lists the target, the
distinctions that matter, the primary sources, and the specialist anchors. It tells you WHO the
specialist is and WHERE their work lives.

## 4. THE COMPARATIVE CORPUS (for STEP 5)

The project keeps the comparative texts on disk — use them to find parallels and oppositions:

- **Tantrāloka** (Dyczkowski, 11 vols, `texts-original/tantraloka-vol{1..11}-dyczkowski.txt`) — the
  same author's encyclopedic synthesis. Great for "the same move, stated differently."
- **Spandakārikā** + 4 commentaries (`spandakarika-dyczkowski.txt`) — the pulse; parallels the
  recognition's reflexivity (sphurattā = spanda).
- **Śivasūtra** (`aphorisms-of-siva-dyczkowski.txt`) — the direct instruction; the Fourth, caitanya.
- **Vijñānabhairava** (`references/vb_lakshmanjoo.json`) — the 112 ways.
- **GRETIL** texts (Tantrāloka, Tantrasāra, Nyāyasūtra, Nyāyabindu, Tarkasaṃgraha, Vākyapadīya) — the
  doctrinal rivals (Buddhist epistemology, grammarian).

**The comparative question to ask for every passage:** *does this move appear elsewhere — in the same
author, in a parallel tradition, or as an opposing position?* That is where the insight lives.

## 6. THE C1 WRITING PROTOCOL (after context gathering)

**Read the governing spec first: `c1/C1-SPEC.md`** (imported verbatim). C1 is a **compact commentary
paragraph**, not a form. It has **two representations**:

```text
c1/source/   the structured editorial object: SUMMARY / FUNCTION / KEY TERMS / LOCAL CONTEXT /
             EXPLANATION / BOUNDARY / RELATED — for QA + API + machine processing
c1/read/     the continuous 100–450-word commentary — what sits beneath the translated passage
             for a reader
```

Write the structured record in `source/`, then compile the continuous commentary into `read/`.

### Universal core (every passage)
```
SUMMARY           what the passage says in plain terms
FUNCTION          its argumentative / ritual / mythic role in the work
KEY TERMS         the technical terms, with their senses
LOCAL CONTEXT     what precedes/follows; what it presupposes
EXPLANATION       the local reading — the insight
BOUNDARY / OPEN   what the passage establishes vs. what is deferred
RELATED PASSAGES  nearby passages that clarify it
```
*C1 is strictly passage-local. Cross-textual parallels (other works) are a separate later layer
(PARALLELS, after THEMES) — gather them as scratch notes in Step 5, never in the C1.*

### Optional modules (only the ones the passage-type needs)
```
ARGUMENT    premises / objection / reply
RITUAL      actor / action / object / sequence / result
DEITY       form / epithets / relations / symbolism
MANTRA      structure / deity / ritual use
COSMOLOGY   entities / hierarchy / correspondences
YOGA        body locus / process / result
NARRATIVE   characters / event / function
```

**The three rules of good C1:**
1. **Intimate and passage-local** — explain what THIS passage does, not what essay to extract.
2. **Grounded** — anchor every load-bearing claim to the text (L0/root kārikā) or reliable scholarship;
   never use our essays as primary evidence.
3. **Honest** — mark the BOUNDARY (what the passage establishes vs. what it commits to). Never smooth an
   obscure passage into false clarity.

**The editorial test:** *Could this commentary plausibly sit immediately beneath the translated
verse/passage in a serious annotated edition?* If yes, it's C1. If it needs a modern comparison, an
original argument, or an essay title, it belongs in THEMES or ESSAYS.

**The Ratié register** (how to write): quote the text, name the move, show what it presupposes, then
say what it means locally. Use the specialist's vocabulary naturally. The voice should be scholarly,
precise, and close to the text — a compact commentary paragraph, not an essay's sweep. **The early,
essay-rich C1s are preserved in `c1/_essay-material-legacy/` as assets for THEMES/ESSAYS — do not
regress to them.**

---

## 7. THE OUTPUT (what each C1 should cite in its header)

Every C1 should carry its context-bundle as a header, so the derivation is transparent:

```markdown
# C1 — <PASSAGE>: <the move>
*C1 base: <the L200/audited file> · <root text> context: <kārikā/sūtra> ·
scholarship: <specialist, work, chapter> · reference argument: <your essays/dossiers>.*
```

This makes the C1's provenance inspectable: the reader (and the higher layers) can see exactly which
text, which scholar, and which synthesis it rests on.

---

## 8. CHECKLIST (before you write)

```
[ ] 1. Located the passage + its root source (work/section/lines/kārikā)
[ ] 2. Read the argument map; noted function + presuppositions + what it prepares
[ ] 3. Read the L2/L200; noted the load-bearing claims + OPEN items
[ ] 4. Mined the scholarship (specialist reading + verbatim quote + register/vocab)
[ ] 5. Found the comparisons (same author / other works / other traditions)
[ ] 6. Pulled the synthesis (your essays/dossiers on this doctrine)
[ ] 7. Searched externally only what's not on disk (verified, not guessed)
[ ] 8. Confirmed the schema + the three rules (intimate, grounded, honest)
```

## 9. EXAMPLE (what the full pipeline produces)

For the memory-doctrine (V2-A), the context gathering yields:
- **Text:** IPVV V2-A, the caturtho vimarśa, source M00021 29–700, commenting on IPK 1.3 (memory).
- **Local:** the second power (smṛti) after jñāna; prepares the pastness-question (V2-B).
- **Scholarship:** Ratié ch. 2 — memory = re-appropriation (asampramoṣa), the synthesis (anusandhāna)
  presupposes a persisting subject; her register + vocabulary captured.
- **Comparison:** the Spanda (continuity), the Śivasūtra (the Fourth), the Buddhist (the no-self on
  memory).
- **Synthesis:** the memory essays + `ESSAY-ULTIMATE-PROOF` (the eternal knower).

→ The C1 then argues, in Ratié's register: *Abhinavagupta is not defining memory; he is using it to
relocate continuity from the impression to the recognizer — the ground of the eternal self.* That is
grounded (text + Ratié + essay) and insightful (the rival-frame), not a restatement.
