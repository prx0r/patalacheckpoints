These are curated, not exhaustive. Selection criteria: (1) standalone quality — reads great on its own,
(2) intellectual depth — makes the case for Pāṭala, (3) durability — the analysis still matters even as
implementation moves, (4) non-redundant — each adds something the others don't. The originals are
CANONICAL and stay in place; this index is the curator's hand so an agent or reader knows what's worth
reading whole.
