# migration/v2/strategy — the brand · ecosystem · placement · economics view

*The NON-technical strategic reference for Pāṭala. Every claim traces to a canonical doc in
`docs/` — this folder is a faithful synthesis, not a replacement.*

| File | What it is |

| `STRATEGIC-DOSSIER.md` | the full strategic reference: the thesis, the ecosystem position ("OpenAlex for Sanskrit"), the four partner classes, the economics (scarce assets + 84000 model), scholar incentives (paid adjudication, not free cleanup), the funding landscape, go-to-market (pilots + 12-month roadmap), the product doctrine (5 permission-scoped surfaces), the first-product doctrine (Translation Audit + IPVV Benchmark + Autonomous Factory), the organisation framing (one infra, several interfaces), and the source map |

Imported from R2 `patalaproducts` and formalized against the v2 layers. |

## How this relates to v2

- **This folder** = the *why* and the *who* (brand, ecosystem, placement, economics, organisation).
- **`PATALA-V2-SPEC.md` / `LAYERS.yaml` / `LAYER-MAPPING.md` / `MODULES.md`** = the *how* (the build).

The same Pāṭala is described from both sides. The strategy folder exists so a conversation about
"what Pāṭala is / who we partner with / how it's funded / how we enter the market" can happen without
touching technical detail — and so no strategic claim is ever detached from its source doc.
