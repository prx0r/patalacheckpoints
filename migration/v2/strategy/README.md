## How this relates to v2

- **This folder** = the *why* and the *who* (brand, ecosystem, placement, economics, organisation).
- **`PATALA-V2-SPEC.md` / `LAYERS.yaml` / `LAYER-MAPPING.md` / `MODULES.md`** = the *how* (the build).

The same Pāṭala is described from both sides. The strategy folder exists so a conversation about
"what Pāṭala is / who we partner with / how it's funded / how we enter the market" can happen without
touching technical detail — and so no strategic claim is ever detached from its source doc.
