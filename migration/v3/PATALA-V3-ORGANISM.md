### The five organ-systems (how the organism is organised)

**1. THE NERVOUS SYSTEM — Hermes (execution)**
The agent runtime that schedules and executes. Pāṭala decides; Hermes runs. Replaceable via a
`RuntimeRouter`. *[Layer 12]*

**2. THE SKELETON — the kernel + one derivation graph (truth)**
The 17 proven kernels (ip-graph `lib/`) holding identity, authority, events, reducers, gates,
staleness. Every object derives from source through a proof path. *[Layers 0-5]*

**3. THE DIGESTIVE SYSTEM — the reactive factory (transformation)**
Takes crude (source) → refines it layer by layer (proof → commentary → argument → synthesis), gated
by review, recompiling only what staleness marks. *[Layer 3]*

**4. THE REPRODUCTIVE SYSTEM — the production organism (propagation)**
Turns verified synthesis → essay → render → publish → distribute (`.meta`: workengestation → renderio →
reception → sites). The organism reproduces its knowledge outward. *[Layers 7-10]*

**5. THE SENSORY SYSTEM — the consumer read-plane + organism (reception)**
How the world experiences it (compiled static bytes) AND how it learns (consumer-as-probe → new
questions/cruxes → back into the graph). The loop that makes it an organism, not a database. *[Layers
9-10]*
